# Contributing

Use Node 24 or newer, run `npm ci`, and start `npm run dev`. Before submitting a change, run `npm run verify` and `npm audit`. Keep the lockfile in dependency changes.

Preserve crypto-only filtering, freshness checks and the meaning of unavailable values. Do not manufacture history or substitute estimates for measured metrics. Avoid extra polling and unbounded caches. Retain keyboard focus, reduced-motion support, day/night contrast and chart attribution.

For security fixes, add a regression at the public HTTP or data boundary. Inspect visual changes in both themes and a narrow viewport. See `DESIGN.md`.

Never commit credentials, runtime data, private screenshots or personal machine paths. The explicit manifest in `scripts/release-check.mjs` defines the public source release; update it intentionally for new top-level files.
