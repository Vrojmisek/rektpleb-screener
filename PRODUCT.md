# Product

REKTPLEB is a local-first crypto perpetual-market screener for people who scan live price changes, volume, funding and open interest, then inspect a chart.

The product is read-only: no trading keys, accounts, order execution or financial transactions. Core data comes from public Binance and Hyperliquid APIs. Explicit USDC pairs and traditional-finance instruments are excluded. Missing measurements remain visibly unavailable.

The interface is English, supports day/night themes and large readable rows, and preserves preferences locally. The right panel shows the latest qualifying market move from public exchange data by default. The optional TRADING COPILOT connector can replace it with a saved image. Alerts require an active browser and running local server.

The source release installs with Node and npm alone. It contains no private state, credentials, private images or work-session artifacts. Third-party attribution remains visible and license texts accompany distribution.
